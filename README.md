# CAD

Source-controlled CAD projects and the code used to generate them.

## Projects

- [\`projects/tactile-dice\`](projects/tactile-dice/) — tactile, kid-friendly d6 prototypes targeting a Bambu Lab P2S workflow.

## Repository policy

Text-based parametric source is canonical. Generated manufacturing/interchange files such as STL, STEP, and 3MF are normally regenerated rather than committed. Exact prototype or print-ready binaries can be attached to tagged GitHub releases when they become useful handoff artifacts.
